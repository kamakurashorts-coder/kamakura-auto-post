Kamakura Auto Shorts

Kamakura Auto Shorts é uma ferramenta de uso pessoal desenvolvida para auxiliar no gerenciamento e na publicação automatizada de vídeos nos canais autorizados pelo próprio usuário.

Integração com YouTube

A ferramenta utiliza os serviços da YouTube Data API para autenticar contas autorizadas, enviar vídeos, definir informações dos vídeos e acompanhar o processamento dos uploads.
